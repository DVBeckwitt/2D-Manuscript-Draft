# PbI₂ matrix and stacking captions

Use the short caption beneath each figure. The shared key can accompany the set or go in presentation notes.

## 2H

Registry and trilayer orientation remain fixed, giving a one-trilayer repeat. The numbered path shows the example beginning at 0+. Each unnumbered diagonal cell repeats the same rule for another starting state.

## 6H

Registry cycles in opposite directions for the two handed parents, with fixed trilayer orientation and a three-trilayer repeat. The unnumbered cells in each lower block form the corresponding cycle with the opposite (−) trilayer orientation.

## 4H

Registry and trilayer orientation alternate, giving a two-trilayer repeat. Each unnumbered pair forms an equivalent cycle beginning at registry 1 or 2, a lateral translation of that panel’s numbered example.

## Shared key

Each state is one I–Pb–I trilayer. State labels 0, 1, and 2 specify basal registry, and their +/− signs specify trilayer orientation. Signs in the parent names 6H± and 4H± instead distinguish handed transition laws. Matrix rows give the current state and columns the next state. Teal cells have probability 1 and white cells have probability 0. Numbered outlines trace the example beginning at 0+, with matching numbers on the state sequence and stack interfaces. Read stacks upward. Two full repeats are followed by a faded first trilayer of the next repeat, and the bracket marks one repeat. Pb is gray and I is purple. The atomic drawings are schematic projections with independently chosen lateral and vertical scales.
